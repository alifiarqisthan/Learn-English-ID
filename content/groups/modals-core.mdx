## Welcome to Core Modals

Modal verbs sit before the main verb (always V1) and add layers of meaning about ability, permission, obligation, and possibility.

| Modal | Core meaning | Example |
|---|---|---|
| **can / could** | Ability, permission, possibility | I **can** swim. You **could** try again. |
| **must / have to** | Strong obligation, deduction | You **must** register. She **must be** tired. |
| **should / ought to** | Advice, expectation | You **should** see a doctor. |
| **may / might** | Possibility | It **may** rain. She **might** be late. |
| **will / would** | Future, conditional, polite request | **Would** you help me? |
