## Welcome to Causative Verbs

Causative verbs express that someone arranges for another person or service to perform an action.

| Structure | Example |
|---|---|
| **have + object + V3** | I **had my hair cut** yesterday. |
| **get + object + to V1** | She **got her assistant to book** the flights. |
| **make + object + V1** | The teacher **made us rewrite** the essay. |
| **let + object + V1** | My manager **let me leave** early. |
| **help + object + (to) V1** | He **helped me (to) move** the boxes. |
