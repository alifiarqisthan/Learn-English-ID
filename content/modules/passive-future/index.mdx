## Explanation

Passive voice extends naturally to future constructions and infinitive structures — both common in academic, professional, and formal English.

### Future Simple Passive

```
will + be + V3
```

| Active | Passive |
|---|---|
| They **will announce** the results tomorrow. | The results **will be announced** tomorrow. |
| The committee **will review** all applications. | All applications **will be reviewed**. |
| Someone **will deliver** the package on Friday. | The package **will be delivered** on Friday. |

### "Going to" Passive

```
am / is / are + going to + be + V3
```

> The road **is going to be** widened next year.
> New staff **are going to be** hired in January.

### Future Continuous Passive (less common)

```
will + be + being + V3
```

> The building **will be being** renovated during the conference. *(rarely used — usually replaced by future simple passive)*

### Passive Infinitive structures

The passive infinitive (**to be + V3**) appears after many verbs, adjectives, and modal-like expressions:

#### After modal-like verbs

| Structure | Example |
|---|---|
| need + to be + V3 | This form **needs to be** completed in full. |
| have + to be + V3 | All receipts **have to be** submitted. |
| ought to be + V3 | The results **ought to be** verified. |
| seem / appear + to be + V3 | The issue **seems to be** resolved. |
| tend + to be + V3 | Errors **tend to be** found at this stage. |
| be supposed + to be + V3 | The report **is supposed to be** ready. |

#### After adjectives

| Structure | Example |
|---|---|
| It is + adjective + to be + V3 | It is important **to be** informed. |
| Subject + adjective + to be + V3 | The data **is likely to be** published soon. |
| Subject + adjective + to be + V3 | The proposal **is expected to be** approved. |

#### After nouns

> There is a lot **to be** done before the deadline.
> The decision **to be** made is a difficult one.

### Passive with "be about to"

```
am / is / are + about to + be + V3
```

> The announcement **is about to be** made.
> The results **are about to be** released.

### Perfect passive infinitive

```
to have been + V3
```

Used to describe a completed passive action relative to a point in time:

> The documents appear **to have been** altered.
> She claims **to have been** misquoted.
> The error is thought **to have been** introduced during the editing process.

## Bahasa Indonesia

### "Akan" + di- = future passive

Indonesian: *Hasilnya **akan diumumkan** besok.* = The results **will be announced** tomorrow.

The structure maps directly, but English requires the full "will be + V3" — no shortcuts.

### "Perlu" / "Harus" + passive

Indonesians often translate *perlu ditinjau* (needs to be reviewed) as "needs reviewed" — missing "to be":

| Bahasa Indonesia | Wrong | Correct |
|---|---|---|
| Formulir ini perlu diisi lengkap. | This form needs filled in. ❌ | This form **needs to be** filled in. ✅ |
| Semua tagihan harus diserahkan. | All invoices have submitted. ❌ | All invoices **have to be** submitted. ✅ |

### "Tampaknya" / "Kelihatannya" + passive

*Masalahnya tampaknya sudah diselesaikan.* = The issue **seems to have been** resolved.

The perfect passive infinitive (*to have been + V3*) captures "sudah + di-" (already completed in the past, but we're talking about it now).

## Common Mistakes

**1. Dropping "to be" in infinitive passive**
- ❌ This form needs completed.
- ✅ This form **needs to be** completed.

**2. "Will been" — wrong passive future**
- ❌ The results will **been** announced.
- ✅ The results **will be** announced.

**3. "Will be been" — double auxiliary error**
- ❌ The letter will be been sent.
- ✅ The letter **will be** sent.

**4. "Seem to be" vs "seem to have been"**
- "The problem **seems to be** solved." *(currently in solved state)*
- "The problem **seems to have been** solved." *(completed sometime before now)*

**5. "Is going to be" agreement**
- ❌ New policies **is going to be** introduced.
- ✅ New policies **are going to be** introduced. *(plural → are)*

**6. Using active infinitive where passive is needed**
- ❌ There is a lot to **do** before the deadline. *(agent = we, active OK)*
- ❌ The report **is supposed to submit** by Friday. *(wrong — report doesn't submit itself)*
- ✅ The report **is supposed to be submitted** by Friday.

## Quick Summary

- Future simple passive: **will + be + V3** — *Results will be announced.*
- "Going to" passive: **is/are + going to + be + V3** — *The road is going to be widened.*
- Passive infinitive: **to be + V3** — *This needs to be checked.*
- After: need, have, ought, seem, appear, tend, be supposed — all use **to be + V3**.
- Perfect passive infinitive: **to have been + V3** — *It seems to have been altered.*
- ❌ "will been" | ❌ "needs completed" | ❌ "is going to be" with wrong agreement.
