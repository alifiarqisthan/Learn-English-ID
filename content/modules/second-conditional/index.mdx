## Explanation

The **second conditional** expresses situations that are **unreal, imaginary, or hypothetical** in the present or future. The speaker does not expect the condition to be true.

### Core Structure

| Clause | Form | Example |
|---|---|---|
| If-clause (condition) | If + past simple | If I had more time… |
| Main clause (result) | would + base verb (V1) | …I would travel the world. |

**Formula:** `If + subject + V2, subject + would + V1`

> If I **won** the lottery, I **would buy** a house.
> She **would study** abroad if her family **agreed**.

The if-clause can come first or second. When it comes first, use a comma.

---

### The Subjunctive "Were"

For the verb **be** in the if-clause, formal English uses **were** for all subjects — not "was."

| Subject | Correct (Formal) | Informal (avoid in writing) |
|---|---|---|
| I | If I **were** rich… | If I was rich… |
| He/She | If she **were** here… | If she was here… |
| It | If it **were** possible… | If it was possible… |

The phrase **"If I were you"** is a fixed expression — always use "were."

> If I **were** you, I would apologise immediately.
> If she **were** taller, she could be a model.

---

### Negatives

Negate either clause independently:

| Clause negated | Example |
|---|---|
| If-clause | If I **didn't have** a car, I would take the bus. |
| Main clause | If he asked me, I **wouldn't tell** him. |
| Both | If she **didn't work** there, she **wouldn't know** about it. |

---

### Other Modals in the Result Clause

**Would** is the most common, but you can use **could** or **might** to soften certainty:

| Modal | Meaning | Example |
|---|---|---|
| would | certain result (hypothetically) | I would call you. |
| could | possibility / ability | I could help you. |
| might | less certain possibility | She might agree. |

> If you practised every day, you **could** become fluent.
> If we left now, we **might** catch the train.

---

### Questions

| Type | Structure | Example |
|---|---|---|
| Yes/No | Would + subject + V1 + if + past simple? | Would you quit if you got a better offer? |
| Wh- | Wh- word + would + subject + V1 + if…? | What would you do if you lost your job? |

> **What would you say** if you met your favourite singer?
> **Would she come** if we invited her?

---

### Comparison: Zero, First, and Second Conditional

| Type | Structure | Meaning | Reality |
|---|---|---|---|
| Zero | If + present, present | General truth / habit | Always true |
| First | If + present, will + V1 | Real future possibility | Likely / possible |
| Second | If + past, would + V1 | Hypothetical / unreal | Unlikely / imaginary |

> Zero: If you **heat** ice, it **melts**. (always true)
> First: If it **rains**, I **will stay** home. (real possibility)
> Second: If I **were** a bird, I **would fly** to Paris. (imaginary)

## Bahasa Indonesia

### "Seandainya / Andaikan"

Bahasa Indonesia menggunakan **seandainya** atau **andaikan** untuk kondisi hipotetis — setara dengan second conditional.

| Bahasa Indonesia | English |
|---|---|
| Seandainya aku punya mobil, aku akan pergi ke sana. | If I had a car, I would go there. |
| Andaikan dia di sini, dia pasti tahu jawabannya. | If she were here, she would know the answer. |
| Kalau aku jadi kamu, aku tidak akan melakukan itu. | If I were you, I wouldn't do that. |

### Perbedaan Penting

Dalam Bahasa Indonesia, tidak ada perbedaan bentuk kata kerja antara kondisi nyata dan hipotetis — konteks dan kata seperti "seandainya" yang membedakannya. Dalam bahasa Inggris, bentuk kata kerja **harus berubah** (past simple di if-clause, would di result clause).

**Kesalahan umum pelajar Indonesia:**

> ❌ If I have a lot of money, I would travel. *(mixes first + second)*
> ✅ If I **had** a lot of money, I would travel.

> ❌ If I am you, I would apologise.
> ✅ If I **were** you, I would apologise.

## Common Mistakes

1. ❌ *If I **was** you, I would be careful.* → ✅ *If I **were** you, I would be careful.* *Why:* The subjunctive "were" is required for all subjects after "if I/he/she/it" in formal English.

2. ❌ *If I **would have** more time, I would help you.* → ✅ *If I **had** more time, I would help you.* *Why:* Never use "would" in the if-clause of a second conditional.

3. ❌ *If she **would be** here, she would understand.* → ✅ *If she **were** here, she would understand.* *Why:* "Would" belongs only in the result clause.

4. ❌ *If it **rains** tomorrow, I would stay home.* → ✅ *If it **rained** tomorrow, I would stay home. / If it rains tomorrow, I will stay home.* *Why:* Don't mix first and second conditional structures — choose one level of certainty.

5. ❌ *I would go there if I **have** a car.* → ✅ *I would go there if I **had** a car.* *Why:* The if-clause needs past simple in a second conditional.

6. ❌ *If I were rich, I **will buy** a big house.* → ✅ *If I were rich, I **would buy** a big house.* *Why:* The result clause needs "would," not "will."

7. ❌ *She could help you if she **would know** the answer.* → ✅ *She could help you if she **knew** the answer.* *Why:* The if-clause takes past simple, not "would + verb."

8. ❌ *What would happen if someone **will find** out?* → ✅ *What would happen if someone **found** out?* *Why:* "If" clause in second conditional takes past simple.

## TOEFL Practice

Second conditional is common in TOEFL structure questions testing:
- Correct verb tense in if-clauses (past simple, not present or would)
- Subjunctive "were" vs "was"
- Modal choice in the result clause (would/could/might)

**Strategy:** When you see an if-clause with past simple and a result clause with would/could/might, check that neither clause uses "would" where a past tense is needed.

## Quick Summary

- Second conditional = If + **past simple**, **would** + base verb
- Use it for **hypothetical, unreal, or imaginary** present/future situations
- Use **were** (not was) for all subjects with the verb "be" in the if-clause
- **Never** put "would" in the if-clause
- Result clause can use **would, could, or might** depending on certainty
- **If I were you** is a fixed expression — always "were"
- Compare: First conditional (real possibility) vs Second (hypothetical)
- Indonesian equivalent: **seandainya / andaikan** + verb (but English requires tense change)
