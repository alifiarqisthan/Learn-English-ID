## Explanation

Modal verbs combine with passive voice to express necessity, obligation, possibility, advice, and deduction about actions received by a subject. This structure is extremely common in academic and professional English.

### Formula

```
Modal + be + V3
```

The "to be" after a modal is always the **base form "be"** — never "is", "was", "been", or "being".

### Core modal passives

| Modal | Meaning | Example |
|---|---|---|
| **must be** | strong obligation / logical certainty | All forms **must be** submitted by Friday. |
| **should be** | advice / expectation | The results **should be** verified. |
| **can be** | possibility / ability | This feature **can be** disabled in settings. |
| **could be** | possibility / past ability | The error **could be** caused by a software bug. |
| **may be** | possibility (present/future) | Your application **may be** rejected without ID. |
| **might be** | weaker possibility | The delay **might be** related to weather. |
| **would be** | conditional / hypothetical | More funding **would be** welcomed. |
| **shall be** | formal obligation (formal/legal) | The findings **shall be** reported to the board. |
| **ought to be** | mild obligation / expectation | This document **ought to be** signed. |

### Negative modal passives

```
Modal + not + be + V3
```

> This information **must not be** shared outside the team.
> The deadline **should not be** missed.
> The form **cannot be** submitted without a signature.

### Modal perfect passive — past deduction or regret

```
Modal + have + been + V3
```

Used for deductions or regrets about past situations:

| Structure | Meaning | Example |
|---|---|---|
| must have been | logical deduction (past) | The data **must have been** corrupted during transfer. |
| should have been | past regret / criticism | The report **should have been** submitted yesterday. |
| could have been | past possibility | The error **could have been** avoided. |
| might have been | past possibility (weaker) | The file **might have been** deleted accidentally. |
| would have been | conditional (past) | More resources **would have been** allocated if requested. |
| can't have been | logical deduction (past negative) | That **can't have been** approved — it's against policy. |

### Questions with modal passives

```
Modal + subject + be + V3?
```

> **Should** this form **be** completed in English?
> **Can** the deadline **be** extended?
> **Must** all receipts **be** attached?

### Common academic and formal passive modal phrases

| Phrase | Example |
|---|---|
| should be noted that | It **should be noted that** the sample size was limited. |
| must be considered | Several factors **must be considered**. |
| can be seen | This trend **can be seen** in Figure 3. |
| may be found | Further details **may be found** in the appendix. |
| should not be confused with | This term **should not be confused with** the earlier definition. |

## Bahasa Indonesia

### Indonesian modal passives

Indonesian modals (*harus, boleh, bisa, perlu, sebaiknya*) combine with di- passive:

| Bahasa Indonesia | English |
|---|---|
| Formulir ini **harus diisi** lengkap. | This form **must be** filled in completely. |
| Data ini **boleh diakses** oleh semua anggota. | This data **can be** accessed by all members. |
| Laporan **sebaiknya diserahkan** lebih awal. | The report **should be** submitted early. |

The mapping is direct, but learners often add an unnecessary agent or use the wrong "be" form.

### "Harus" + passive — the "must be" trap

Indonesian learners sometimes write "must is" or "must was" because they try to conjugate "be":
- ❌ This form **must is** completed.
- ❌ The form **must was** completed.
- ✅ This form **must be** completed.

After a modal, **"be" is always the base form** — no conjugation.

### Modal perfect passive — "seharusnya sudah"

*Laporan itu seharusnya sudah diserahkan kemarin.* = The report **should have been** submitted yesterday.

The Indonesian *sudah* triggers the perfect, but English requires the full structure: modal + have + been + V3.

## Common Mistakes

**1. Conjugating "be" after a modal**
- ❌ The form must **is** completed.
- ❌ The results should **be** announced. *(this is actually correct!)*
- ❌ The meeting must **was** cancelled.
- ✅ The meeting **must be** cancelled. / The meeting **must have been** cancelled. *(past)*

**2. Using "been" instead of "be" after a modal (for present)**
- ❌ All fees must **been** paid.
- ✅ All fees **must be** paid.

**3. Using "be" instead of "have been" for past deduction**
- ❌ The file must **be** deleted — it was there yesterday.
- ✅ The file **must have been** deleted.

**4. Wrong modal for the meaning**
- ❌ This data **must be** misinterpreted. *(too strong — certainty)*
- ✅ This data **might be** misinterpreted. *(possibility)*

**5. Missing "not" placement in negative**
- ❌ This form **must be not** shared.
- ✅ This form **must not be** shared. *("not" comes after the modal, before "be")*

**6. Modal passive in questions — wrong word order**
- ❌ Be the form completed before submission?
- ✅ **Should** the form **be** completed before submission?

## Quick Summary

- Modal passive: **modal + be + V3** — *must be submitted, should be checked*.
- "Be" after a modal is always the **base form** — never is/was/been.
- Negative: **modal + not + be + V3** — *must not be shared*.
- Modal perfect passive: **modal + have + been + V3** — *should have been submitted, must have been deleted*.
- Modal perfect = past deduction, past regret, or past possibility.
- Common: must be, should be, can be, could be, may be, might be, would be.
- Question: **Modal + subject + be + V3?** — *Should this be completed?*
