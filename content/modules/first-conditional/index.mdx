## Explanation

The **first conditional** describes **real or likely future situations**. The condition is possible, and the result will follow if the condition is met.

### Structure

```
If + present simple, will + V1
```

| Clause | Tense | Example |
|---|---|---|
| If-clause (condition) | present simple | If it **rains** tomorrow… |
| Result clause | will + V1 | …I **will stay** home. |

> The if-clause uses **present simple**, NOT "will". This is the most common mistake.
> - ❌ If it **will rain**, I will stay home.
> - ✅ If it **rains**, I will stay home.

### Common result clause variations

"Will" is not the only modal in first conditional results:

| Modal | Meaning | Example |
|---|---|---|
| will | definite future result | If you study, you **will pass**. |
| can | ability/permission | If you finish, you **can leave** early. |
| may / might | possible result | If it's late, she **might cancel**. |
| should | advisable result | If you're tired, you **should rest**. |
| must | obligation | If you break it, you **must replace** it. |

### Negative first conditional

```
If + don't/doesn't + V1, won't + V1
```

> If you **don't** study, you **won't** pass.
> If she **doesn't** call, I **won't** wait.
> If they **don't** submit on time, they **will lose** marks.

### Questions in first conditionals

> What **will** you do if it **rains**?
> **Will** you come if I **invite** you?
> If you **pass**, **will** you celebrate?

### Unless = if not

"Unless" can replace "if not" in first conditionals:

| If not | Unless |
|---|---|
| If you **don't** hurry, you'll be late. | **Unless** you hurry, you'll be late. |
| If it **doesn't** stop raining, we'll cancel. | **Unless** it stops raining, we'll cancel. |

> "Unless" always uses an affirmative verb in the unless-clause.

### Zero vs first conditional

| Type | Use | Result clause |
|---|---|---|
| Zero | Universal truth | If you heat ice, it **melts**. |
| First | Real future possibility | If you heat it, it **will melt**. |

The difference is certainty: zero = always true; first = likely in this specific situation.

## Bahasa Indonesia

### "Jika/Kalau" + future

Indonesian uses *jika/kalau* + will-equivalent for the first conditional. The future marker *akan* appears in the result clause:

| Bahasa Indonesia | English (first conditional) |
|---|---|
| Kalau kamu belajar, kamu akan lulus. | If you study, you **will pass**. |
| Jika hujan, kami akan membatalkan acara. | If it rains, we **will cancel** the event. |
| Kalau kamu tidak pergi, aku tidak akan pergi juga. | If you **don't** go, I **won't** go either. |

### Common interference errors

**1. Using "will" in the if-clause**

Indonesian *kalau kamu akan pergi* (if you will go) → students carry this into English:
- ❌ If you will come, I will be happy.
- ✅ If you **come**, I will be happy.

**2. Confusing "unless" with "if not"**

*Kecuali* = unless. But students sometimes write "unless you don't" (double negative):
- ❌ Unless you don't hurry, you'll be late.
- ✅ Unless you **hurry**, you'll be late. (= if you don't hurry)

## Common Mistakes

**1. "Will" in the if-clause**
- ❌ If she will pass the exam, she will celebrate.
- ✅ If she **passes** the exam, she will celebrate.
- *Why:* The if-clause always uses present simple, even when referring to the future.

**2. Using past tense in the if-clause**
- ❌ If she studied tomorrow, she would pass.
- ✅ If she **studies** tomorrow, she will pass.
- *Why:* Past tense in the if-clause signals a second conditional (hypothetical). For a real future → present simple.

**3. "Unless" + negative verb**
- ❌ Unless you don't bring your ID, you can't enter.
- ✅ Unless you **bring** your ID, you can't enter.
- *Why:* "Unless" already means "if not" — adding "don't" creates a double negative.

**4. Forgetting "will" in the result clause**
- ❌ If she studies hard, she pass the exam.
- ✅ If she studies hard, she **will pass** the exam.
- *Why:* The result clause of a first conditional needs "will + V1".

**5. Mixing first and second conditional structures**
- ❌ If I have time, I would call you.
- ✅ If I have time, I **will** call you. *(first — real possibility)*
- ✅ If I **had** time, I **would** call you. *(second — hypothetical)*
- *Why:* First: present simple + will. Second: past simple + would. Don't mix them.

**6. Using "may" in the if-clause**
- ❌ If it may rain, bring an umbrella.
- ✅ If it **rains**, bring an umbrella.
- *Why:* The if-clause uses present simple — not modals like "may" or "might".

## Quick Summary

- **First conditional**: If + present simple, will + V1
- Expresses **real or likely future situations**
- If-clause: **present simple** (NEVER "will") — "If it rains…"
- Result clause: **will + V1** — "…I will stay home."
- Other modals in result clause: can, may, might, should, must
- **Unless** = if not: "Unless you study, you won't pass."
- "Unless" takes affirmative verb: never "unless you don't"
- Zero vs First: zero = universal truth (melts); first = specific future (will melt)
